Updates

Patch notes · Oct 6, 2026

  • New: clipboard wrap buttons. Put $() in a button's text, and clicking it copies that text with whatever is on your clipboard dropped in where $() was. If your browser blocks clipboard reading, you're asked to paste the text instead.
  • Filters and search now hide buttons that don't match, and show a message when nothing does.
  • Drag-to-reorder now sticks, and works on touchscreen laptops too.
  • Ctrl/Cmd+K now jumps to the search box.
  • Long-press a button on a phone or tablet to open its menu.
  • Selected buttons are now highlighted with a check mark.
  • You can now edit a button's text, not just its title ("Edit title & text" in the menu).
  • Cancel now works in the Edit and Edit tags windows.
  • Tag color "Reset" only applies when you click Save, and really goes back to the automatic color.
  • Import now accepts .csv, .tsv and .txt files, and the window says which formats work.
  • Clear All now also clears custom tag colors.
  • Default names ("Button 1", "Button 2"…) no longer repeat after reloading the page.
  • Fixed a slowdown that built up over time, and a security issue with imported tag names.
  • The "Go to Buttons" link works wherever the site is hosted, and the site's main address now opens this page.
